# Ghost Protocol CTF 2.0 — Operations Console

A single self-contained page built for the **Ghost Protocol CTF 2.0** online qualifier
(17 October 2026, NIET Greater Noida × Cyber Invaders).

### → Open `gpctf-console/index.html` in a browser.

That is the whole thing. One file, no build step, no server, no network. CSS, JavaScript and
the search index are all inlined, so it works from `file://` and inside a sandboxed preview.

## Where the content comes from

- **Official category pages** — `gpctf2.0.cyberinvaders.tech/categories/<slug>`, captured
  14 Oct 2026. Each publishes 3 intro paragraphs, 6 sub-types, 8 tools, 5 preparation steps and
  3 adjacent disciplines. All nine linked categories are captured verbatim.
  *Miscellaneous is listed on the site but unlinked (404) — its content is authored and labelled.*
- **Official rules** — appear only on the Unstop registration listing, not on the organisers'
  website (no rules page exists there).
- **`Ghost-Protocol-CTF-2.0-Round-1-Field-Manual.pdf`** — the domain model, clock blocks,
  attack order and command reference.
- **`Ghost-Protocol-Playbook-CyLab-and-OverTheWire.pdf`** — the 57 step-by-step walkthroughs.

## Known source conflict

The organisers' website says Round 1 is **12 hours**; their Unstop listing says the
qualification window is **72 hours**. Both are recorded on the page. The advice given is to
plan for 12 — if it is 72 you have spare capacity, whereas planning for 72 and getting 12
would collapse the schedule.
